# База знаний After: состав и приёмка версии 0.18.0

Обновлено 31 октября 2026 года. Версия выпуска — `0.18.0 / build 37`,
предыдущая опубликованная версия — `0.17.6.5 / build 34`. Проверки выполняются
на отдельных библиотеках и точном установочном пакете. Они не устанавливают
приложение поверх личной библиотеки. Аппаратная проверка переключения
Bluetooth/USB-устройств остаётся отдельным незавершённым пунктом.

## Что реализовано

| Путь пользователя | Реализация | Ограничение |
| --- | --- | --- |
| Включить смысловой поиск | Настройки → встроенная модель After → явная подготовка → проверка → индекс | Apple Silicon; первая загрузка компонентов требует сети, inference локальный |
| Найти заметку или материал встречи | Общий semantic маршрут индексатора, поиска и помощника | Только текущая разрешённая область; индекс производный |
| Получить тему из встреч и заметок | Обычный экран базы знаний, общий inventory, существующие актуальные vectors | Предложения, не автоматическое изменение оригиналов; покрытие/приближённый поиск показаны |
| Связать заметку со встречей | Ручные связи, обратные ссылки, удаление/Undo, открытие проверенной версии | Изменённый материал недоступен; точное восстановление содержимого допустимо |
| Передать агенту выбранные материалы | Меню задачи → снимок → выбор подключения по коду → полный preview → подтверждение | Копия задачи и выбранных заметок на 24 часа; это не живой доступ ко всей библиотеке |
| Получить результат агента | Настоящий stdio MCP search/read/report; отчёт, артефакты и источники в Истории | Отчёт обозначен как сообщение агента; статус исходной задачи не меняется автоматически |
| Отозвать доступ | Кнопка у снимка или отдельный общий переключатель снимков | Новые ответы запрещаются; уже полученные агентом байты удалить у него невозможно |

Темы смешанных материалов и сохранённые ручные связи — разные сущности.
Темы можно просматривать и открывать; сохранённые подборки заметок продолжают
работать как прежде. Полный редактор смешанных подборок и генерация развёрнутых
страниц тем не объявляются готовыми возможностями этой сборки.

## Решения, устранившие прежние блокеры

Нормативный [контракт](knowledge-product-contract.md) заменяет попытку заставить
старую версию соблюдать неизвестные ей блокировки.

1. Основная SQLite остаётся совместимой schema v1 с добавочными KB-таблицами.
   Отдельное хранилище `agent-shares/shares.sqlite` содержит утверждённые копии,
   полномочия сессий, read receipts и отчёты. Старые task claims и settings не
   являются разрешением на эти копии. Старый редактор может менять оригинал,
   но это не меняет текст уже просмотренного и одобренного снимка.
2. Ссылка на встречу означает версию содержимого, а не историю рождения файла.
   AI-профиль не входит в её идентичность; доступ проверяется отдельно.
   Явное удаление связи сохраняется. Байт-в-байт восстановление исходника
   допустимо, но не воскрешает удалённую связь.
3. Встроенная модель работает через проверенный дочерний процесс и Unix-сокет.
   Один межпроцессный lease ограничивает inference, native lease согласует его
   с остальными локальными задачами, запись блокирует/отменяет модельную работу.
   Нет скрытой облачной или localhost-подмены при ошибке.
4. Отзыв снимка сериализован с фактической записью MCP-ответа. Медленный клиент
   ограничен абсолютным сроком отправки; partial frame обрывается. Секрет сессии
   хранит сервер, модель не может передать sessionID или подтвердить себе доступ.

Это защита интерфейсов After. Агенту с отдельно выданным shell/file access
нельзя обещать запрет чтения тех же файлов на уровне ОС.

## Проверки и воспроизведение

Все проверки используют отдельные временные библиотеки и синтетические данные.

- `scripts/check_snapshot_agent.py`: реальный MCP, два независимых клиента,
  полный preview/approve/search/read/report/history/revoke, повтор операций,
  неправильные источники, артефакты и блокировка настоящей pipe. Параметр
  `--old-library` включает реальное выпущенное ядро как старого писателя.
- `scripts/check_kb_legacy_compat.py`: две реальные dylib в отдельных процессах;
  concurrent saves, очередь, ссылки, аварийное восстановление расширения,
  изменённый/точно восстановленный транскрипт, tombstones и future-schema refusal.
- `scripts/check_managed_semantic.py`: подготовленные проверенные assets,
  реальный индекс/межъязычный поиск, recording admission, отзыв конфигурации,
  завершение дочернего процесса. Проверено под запретом всей IP-сети.
- `scripts/eval_managed_semantic.py`: real FFI model regression на двух наборах
  по 30 заметок. На контрольном наборе 78 релевантных из 81 подсказки;
  recall@3 65%, ответы для 30/30 запросов. Порог 0,43 только для точной модели
  и вручную подтверждаемых подсказок.
- `scripts/eval_mixed_product.py`: frozen corpus с отдельными calibration и
  holdout. Calibration 4/4; holdout — 7 верных пар из 7 предложенных при 8
  ожидаемых, recall/покрытие положительных источников 87,5%. Порог 0,58 выбран
  до holdout и после него не менялся. Один пропуск, 0 ложных пар на этом корпусе.
  Это маленькая синтетическая проверка, не оценка личной библиотеки и не
  гарантия отсутствия ошибок. Results/хеши находятся в `scripts/fixtures/`.
- Нативные проверки: `--check-agent-snapshot`, `--check-knowledge-links`,
  `--check-knowledge-topics`, `--check-assistant-read`; плюс существующие checks
  локализации, задач, навигации, записи и общие Rust/Python/Swift contracts.

`verify.py integration` включает настоящий snapshot MCP; `verify.py native`
включает сценарий снимка. Реальные модели остаются явными opt-in проверками,
чтобы стандартные тесты не загружали компоненты и не запускали сетевые запросы.

## Перед личной установкой

Сначала проверить точный собранный PKG: единственный payload After.app,
отсутствие install scripts, подписи/целостность, источник сборки, затем запустить
ключевые проверки на извлечённых из этого PKG бинарниках. Состояние этой
конкретной проверки записывается в локальный QA-отчёт рядом с пакетом.

Физическое подключение/отключение микрофона и наушников пользователь отложил.
Автоматические тесты захвата и финализации не заменяют эту аппаратную проверку.
Публикация, переименование репозитория и установка не выполняются автоматически.

## Дальнейшее развитие, не скрытые release blockers

Живой постоянно обновляемый grant на библиотеку, отдельная защищённая служба
хранения, редактор смешанных подборок, генерация страниц тем и широкая оценка
на реальных библиотеках — отдельные возможности. Ранние исследования
`scoped_agent`/incarnation/XPC сохраняются как экспериментальные модули и не
используются для утверждения безопасности текущего snapshot MCP.
