# Настройка

## Запись

Для голоса нужен доступ к микрофону; для звука звонка и видео — разрешение macOS на запись экрана и системного аудио. Приложение запросит нужный доступ перед записью.

В параметрах записи выберите качество MP3: 64, 128 или 192 кбит/с. Видео включается отдельно: весь выбранный экран, до 720p, до 1080p или исходное разрешение, H.264, 30 кадров/с. В кадр попадают меню, Dock и другие окна.

Параметры доступны перед записью и в **Настройках → Запись**. Модели можно установить позже; начать запись можно без них.

Если после обновления «После» macOS снова запрашивает запись экрана при включённом
разрешении, завершите «После» через **⌘Q** и сбросьте разрешение только этого приложения:

```bash
tccutil reset ScreenCapture app.posle.meetings
open "/Applications/После.app"
```

Снова разрешите запись в настройках macOS и перезапустите приложение, если система
предложит это. Текущие сборки без личного сертификата Apple могут требовать такого
подтверждения после обновлений; библиотека и записи сохраняются.

## Распознавание речи

В **Настройках → Распознавание речи** выберите **На Mac** или **Облако**.

- **На Mac:** выберите Parakeet или Whisper и нажмите **Скачать / проверить**. Модель и компоненты устанавливаются отдельно; после установки локальное распознавание работает офлайн.
- **Уже скачанная модель:** откройте **Использовать скачанную модель → Найти на Mac** или **Выбрать папку…**. Приложение покажет совместимость найденных файлов; выберите **Использовать**.
- **Облако:** нажмите **Подготовить компоненты на Mac**, выберите сервис, укажите модель и сохраните его API-ключ. Для своего сервиса нужен API `/audio/transcriptions`.

Включите **Разделять собеседников** и задайте число участников, включая себя, если оно известно. Количество и имена можно уточнить для готовой встречи.

Для облачного ответа выберите формат, который поддерживает модель. Обычный JSON содержит текст без таймкодов: ссылки будут приблизительными, точное разделение собеседников недоступно. Для таймкодов нужен Verbose JSON, для меток голосов от сервиса — Diarized JSON. Разделение голосов по таймкодам без готовых меток требует локальных компонентов.

## Конспект и карточки

В **Настройках → Конспект и карточки** способ обработки текста настраивается отдельно от распознавания речи.

### На Mac

Выберите источник **После**, **Ollama** или **LM Studio**.

- **После:** выберите модель и нажмите **Подготовить ИИ**. Если компонентов ещё нет, приложение предложит сначала установить их в разделе распознавания речи. Существующий файл можно выбрать в **Подключить файл GGUF**.
- **Ollama:** откройте Ollama с установленной локальной моделью. Обычный адрес — `http://127.0.0.1:11434`.
- **LM Studio:** загрузите модель и включите сервер в разделе Developer. Обычный адрес — `http://127.0.0.1:1234`.

Для внешнего источника нажмите **Найти модели** и выберите установленную модель из списка. Скачивание моделей Ollama и LM Studio выполняется в этих приложениях.

### Облако

**ChatGPT (подписка)** использует лимиты подходящего аккаунта без API-ключа. Доступные модели показывает OpenAI; [инструкция по подключению](chatgpt.md).

**OpenAI API, OpenRouter, Polza или свой провайдер:** сохраните ключ выбранного сервиса и укажите ID его модели. API оплачивается отдельно от подписки ChatGPT, по тарифам провайдера.

Для своего текстового сервиса нужен совместимый Chat Completions или Responses API и базовый HTTPS-адрес, например `https://example.com/v1`. HTTP разрешён только для сервера на этом Mac. Ключ от одного сервиса не даёт доступа к другому.

В **Дополнительно** выберите формат API и ответа. Если модель не поддерживает JSON Schema, попробуйте JSON или JSON по инструкции. **Проверить подключение** отправляет короткий запрос без встреч; он расходует лимиты выбранного сервиса.

## Календари

Google добавляется через аккаунты macOS с включёнными календарями. Яндекс — как учётная запись CalDAV в системном Календаре с паролем приложения. Затем в «После» откройте **Календарь → Подключить календарь**, разрешите доступ и выберите нужные календари.

Синхронизацией с сервисами управляет macOS. Изменения отправляются при подключении к сети. Повторяющиеся события редактируются в системном Календаре; события календарей только для чтения менять нельзя.

## Оформление

Графит, матовое стекло, светлый/тёмный вид и параметры текста доступны в **Настройках → Оформление**. Нативный Liquid Glass применяется на macOS 26; на macOS 15 используется матовое стекло. Системные настройки прозрачности и контраста имеют приоритет.

## Данные и обновления

Записи и библиотека хранятся на Mac. Папку можно открыть в **Настройках → Данные и экспорт**. Ключи API и сессия ChatGPT хранятся в Связке ключей macOS.

Облачная транскрипция отправляет аудио после подтверждения, облачный конспект — текст встречи. Облачный помощник получает поручение и содержимое выбранной встречи, заметки или задачи.

Обновления доступны в **Настройках → Обновления**. Установка обновляет существующее приложение и сохраняет библиотеку, модели и ключи; перезапуск ждёт окончания записи, обработки и сохранения правок.
