# После / After

Выбранный знак — строчная `a` с засечками и синей точкой на белой плитке. Он используется для русской «После» и английской After. Название и идентификаторы установленного приложения при обновлении сохраняются.

- `packaging/Logo.svg` — иконка с прозрачностью вне плитки.
- `packaging/Wordmark.svg` — надпись `after.` без фона для светлой поверхности.
- `scripts/icon.swift` — PNG во всех размерах macOS, которые сборка упаковывает в `AppIcon.icns`.
- `Sources/PosleApp/BrandArtwork.swift` — монохромный шаблон строки меню и встроенный SVG страницы входа. Проверка входа сравнивает SVG с основным исходником.

Цвета в sRGB: графит `#313538`, точка `#476D90`, плитка `#FFFFFF → #F7F8FA`. Отступ плитки — 50 из 512, скругления и прозрачные углы сохраняют привычный размер в Dock. Нижний край точки оптически выровнен с основанием буквы. В строке меню цвет задаёт macOS.

Буква `a` переведена в собственный фиксированный контур по выбранному эскизу. Остальные буквы надписи основаны на контурах Times New Roman Bold с оптической подгонкой. SVG не содержит текста или ссылок на шрифты; файлы шрифтов не поставляются. Иконка, меню и страница входа работают без загрузок и установленных шрифтов.

Перед выпуском проверьте 16, 32 и 1024 px: просвет буквы, отдельную точку, прозрачные углы, видимость на светлом и тёмном фоне. Варианты с солнцем и полосками не относятся к текущему знаку.
