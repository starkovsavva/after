# After 0.18.1

## Русский

Исправления обработки и более понятная база знаний.

- **Материалы под рукой.** Заметки и встречи видны без готовых связей. Даты различают одинаковые названия, а пустая библиотека предлагает создать заметку или записать встречу.
- **Переходы и история.** Запоздалый ответ не открывает источник после смены папки, запроса или ухода со страницы. История показывает актуальный результат после применения и отмены изменений.
- **Отмена обработки.** Исправлены гонки при отмене и повторном запуске: завершение отменённой задачи не затрагивает новый запуск.
- **Подключения и настройки папок.** Обработка использует подключение и настройки, выбранные для операции. Ошибка доступа к сохранённому ключу показывается до запроса к провайдеру.
- **Сохранение распознавания.** При ошибке сохранения повторного распознавания прежние транскрипт и конспект сохраняются. Устаревший конспект не показывается рядом с новым транскриптом.

## English

Processing fixes and a clearer knowledge base.

- **Materials within reach.** Notes and meetings appear before they have related items. Dates distinguish matching titles, and an empty library offers actions to create a note or record a meeting.
- **Navigation and history.** A delayed response no longer opens a source after you change folders, edit the query, or leave the page. History shows the current result after applying and undoing changes.
- **Cancelling processing.** Fixed timing issues when cancelling and restarting: a cancelled task finishing no longer affects the new run.
- **Connections and folder settings.** Processing uses the connection and settings selected for the operation. An error accessing a saved key is shown before a request reaches the provider.
- **Saving transcriptions.** If saving a new transcription fails, the previous transcript and summary are preserved. An outdated summary is not shown alongside a new transcript.
