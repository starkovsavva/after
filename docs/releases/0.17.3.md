- **Параметры встречи.** После ошибки создания заметки по шаблону можно повторить сохранение. Уже сохранённые параметры остаются на месте; повтор не создаёт лишних изменений и заметок.
- **Клавиатура.** В параметрах встречи работают Enter для сохранения и Escape для отмены.
- **Календарь.** Ошибка загрузки больше не выглядит как отсутствие подключённых аккаунтов. Сначала предлагается повторить чтение; настройка аккаунта показывается после успешного пустого ответа.
