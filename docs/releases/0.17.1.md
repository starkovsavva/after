- **Папки.** Заметная кнопка создания, короткий диалог названия, переименование двойным кликом и выбор встреч из библиотеки.
- **Перемещение.** Папка встречи видна в заголовке. При переносе открывается папка назначения; переключение папок сохраняет доступный раздел задач или карточек.
- **Названия встреч.** Редактирование прямо в заголовке: двойной клик, Return для сохранения, Escape для отмены. Черновики и параллельные изменения защищены от потери.
- **Быстрые заметки.** Черновик сохраняет исходную папку после переключения разделов. Недоступное назначение требует явного выбора.
- **Контекст.** Исправлены подписи облачной обработки, ссылки на встречи другой папки и сохранение папки при копировании заметки.
- **Редактор.** Подсказка пустой заметки выровнена с кареткой при изменении размера текста.
