- **Настройки папок.** Возможности, язык, приоритеты конспекта, контекст о себе, генерация карточек и модель отдельно для каждой папки.
- **Наследование.** Папка использует общие настройки или свой выбор. Явный выбор генерации карточек во встрече имеет приоритет.
- **Рабочий контекст.** Встречи, заметки, задачи и колоды выбранной папки. Новые материалы сохраняются туда же; «Все папки» возвращает общий обзор.
- **Трекеры.** Папка назначения новых задач Google Tasks и Яндекс Трекера. Уже импортированные задачи остаются на месте.
- **Карточки.** Исправлена проверка источников для карточек с вопросом по-русски и ответом по-английски.
- **Распознавание речи.** В настройках уточнено: подписка ChatGPT работает с текстом; облачное распознавание требует API-ключ, локальное работает без него.
- **Сохранность.** Удаление папки сохраняет материалы. Изменения профиля проверяются перед публикацией фоновых результатов.
