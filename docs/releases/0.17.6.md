- **Запись через системный выбор экрана.** После «Начать запись» или «Проверить звук» macOS предлагает выбрать экран и разрешает доступ на эту сессию. Приложение использует выбранный источник напрямую, без повторного запроса общего доступа к записи экрана. Старый сохранённый дисплей больше не блокирует запуск. Для микрофона доступ macOS по-прежнему нужен.
- **Отмена и остановка записи.** Выбор экрана можно отменить без пустой встречи. Выход из приложения отменяет ожидающий запуск. Остановка через меню записи macOS сохраняет исходный файл и предлагает обработать его из встречи.
- **Восстановление фоновых заданий после изменения профиля.** Для конспекта, примера карточки и дополнения заметки появилась команда «Запустить заново…»: она показывает текущие модель и провайдер и создаёт новую операцию. Предыдущая попытка остаётся в истории. Изменение исходной заметки во время подтверждения не отправляет новый текст незаметно.
- **Диагностика обновлений.** Отчёт об ошибке содержит версию, сборку, ревизию исходников и совпадение версий вспомогательных компонентов. Полные пути, ключи и содержимое библиотеки автоматически не включаются. Проверка обновления теперь сверяет также вложенные исполняемые компоненты и удаление старых файлов.

После обновления проверьте короткую запись: выберите экран в окне macOS, запишите речь и звук Mac, остановите и прослушайте результат. Приложение не изменяет разрешения OBS или других программ.
