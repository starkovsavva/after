# After 0.18.0

База знаний, локальный смысловой поиск и работа агента с выбранными материалами.

- **Встречи и заметки по темам.** Открывайте связанные материалы, сохраняйте подборки и добавляйте свои связи. Предложения не меняют исходные записи. База знаний включается в **Настройки → Возможности**.
- **Смысловой поиск внутри After.** Встроенная модель работает на Mac без отдельного сервера и API-ключа. Подготовка в **Настройки → Смысловой поиск** загружает около 810 МБ. Поиск показывает состояние модели; подготовка продолжается при закрытых настройках.
- **Помощник по библиотеке.** Можно попросить найти материал, открыть заметку или встречу, показать последние задачи. Ответы содержат переходы к источникам.
- **Выбранные материалы для агента.** Из меню задачи передайте через MCP точную копию задачи и заметок на 24 часа. Перед подтверждением виден весь текст. В истории появятся отчёты, источники и артефакты с привязкой к снимку. Новую копию нужно подтвердить отдельно; доступ можно отозвать.
- **Аудио до распознавания.** Готовую запись можно прослушать и экспортировать, даже если транскрипта ещё нет. При переключении встреч статус записи относится к нужной встрече.
- **Исправления интерфейса.** Подборки доступны в небольшом окне, смена языка обновляет подписи и даты без потери черновиков, настройки агентов открываются в нужном разделе. Процессы приложения называются After.

Новые возможности включаются по вашему выбору. Переданный снимок не обновляется при редактировании оригинала; отзыв останавливает дальнейший доступ, но не удаляет данные, уже полученные агентом. Автоматические связи — предложения: их качество зависит от содержимого библиотеки.

Подпись обновления Sparkle проверяется. Сборка по-прежнему без нотариализации Apple. Реальное переключение Bluetooth/USB-наушников не проверялось в этой версии; непрерывный звук во время переподключения не гарантируется.
