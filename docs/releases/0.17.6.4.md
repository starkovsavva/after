- **Исправлено зависание видео при продолжающейся записи звука.** Кодировщик H.264 больше не удерживает исходные поверхности ScreenCaptureKit: кадры копируются в собственный ограниченный пул. Это устраняет исчерпание буфера захвата, при котором видео могло оставаться на одном изображении. Сохраняются цвета, точные временные отметки и полная длительность видео со звуком, в том числе при неподвижном экране.
- Системный выбор экрана передаётся в захват без изменения его политики строки меню. Добавлены локализованные описания использования записи экрана.
- Для отказа macOS `-3801` уточнено восстановление доступа, когда разрешение уже включено: завершите «After», удалите его старую запись кнопкой «−» в разделе «Запись экрана и системного звука», затем снова откройте установленную копию и подтвердите доступ. Текущая ad-hoc подпись не гарантирует сохранение разрешений после обновлений; этот релиз не заменяет её сертификатом Apple.

Новый знак After и остальные исправления 0.17.6.3 сохранены. Синтетические проверки воспроизводят зависание старого кодировщика и проверяют исправление, смену кадров, экспорт MP4, звук и отмену запуска. Реальный захват на macOS 26.5.2 отдельно не проверялся.
