# 0.12.3

- **Видео.** Исправлено раннее завершение видеодорожки при неподвижном экране: последний кадр сохраняется до конца звука.
- **Запись.** Отсутствие видеокадров больше не считается успешной записью видео. Исходный звук сохраняется.
- **Доступ macOS.** Сообщения различают отказ в разрешении, недоступный экран и сбой ScreenCaptureKit. Добавлена поддержка сборок с постоянной личной подписью Apple.
