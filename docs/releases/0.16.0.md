- **Выбор возможностей.** Встречи, заметки, конспекты и транскрипты доступны сразу. Карточки, задачи и проекты, календарь, помощник и смысловой поиск включаются отдельно в настройках.
- **Карточки для нужных встреч.** Генерация включается у каждой встречи отдельно. Обычный конспект не изменяет существующие карточки и прогресс повторений.
- **Спокойный интерфейс.** Выключенные разделы, команды и настройки скрыты. Поиск по словам остаётся доступен.
- **Сохранность данных.** Дополнительные возможности выключены по умолчанию, в том числе после обновления. Заметки, задачи, карточки и настройки подключения сохраняются.
- **Редактор карточек.** После сохранения или отмены закрытое окно больше не блокирует обновление и смену возможностей.
