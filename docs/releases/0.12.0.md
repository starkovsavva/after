# 0.12.0

- **Подписка ChatGPT.** Конспекты, карточки, примеры и текстовые поручения без API-ключа.
- **Модели.** Выбор из списка вашего аккаунта и настройка рассуждений. Для Luna доступен режим без рассуждений.
- **Аккаунты.** Несколько подключений, сохранение входа между запусками и отмена задач аккаунта при выходе.
- **Лимиты.** Пауза задач ChatGPT при исчерпании лимита, управление использованием и повтор по вашему выбору.
