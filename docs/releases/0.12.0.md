# 0.12.0

- **Подписка ChatGPT.** Вход в личный аккаунт для конспектов, карточек, примеров и текстовых поручений без API-ключа.
- **Модели.** Выбор из списка, доступного вашему аккаунту, и управление уровнем рассуждений. Для Luna — режим без рассуждений.
- **Аккаунты.** Отдельные подключения, безопасное обновление сессии и остановка заданий при выходе.
- **Лимиты.** Пауза очереди при исчерпании лимита, управление использованием и явный повтор задания.
- **Интерфейс.** Состояния входа, загрузки и ошибок в светлой и тёмной темах. Краткая подсказка о новом подключении.
