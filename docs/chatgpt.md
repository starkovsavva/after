# Подписка ChatGPT

«После» использует официальный Sign in with ChatGPT для локальных приложений с открытым кодом. Нужен подходящий аккаунт ChatGPT Plus или Pro; доступность определяет OpenAI.

1. Откройте **Настройки → Конспект и карточки → Облако → ChatGPT (подписка)**.
2. Нажмите **Continue with ChatGPT**. В браузере выберите личный аккаунт и разрешите использование подписки.
3. Выберите модель из списка вашего аккаунта. Если Luna доступна, она появится в этом списке.
4. При необходимости измените уровень рассуждений. Для Luna доступен режим **Без рассуждений**; **Как у модели** оставляет выбор за моделью.

Конспекты, карточки, примеры и текстовые поручения используют общий лимит Codex / ChatGPT Work. **Управлять лимитами** открывает настройки использования ChatGPT. При исчерпании лимита приложение не переключается на платный API.

Запись и локальное распознавание работают независимо от подписки. Этот способ подключения не поддерживает облачное распознавание аудио.

Сессия хранится в Связке ключей macOS и обновляется автоматически. Выход прекращает её использование. Ожидающие задачи привязаны к выбранному аккаунту: после его смены их нужно запустить заново.

Вход и использование подписки — разные разрешения. Если использование подписки не разрешено, приложение предложит повторный вход. Оно не получает ваши чаты или память ChatGPT.
