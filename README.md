# After

Приложение для Mac: встречи, заметки, задачи и база знаний в одной библиотеке.
Сохраняйте решения и возвращайтесь к источнику, когда нужны подробности.

**[Скачать последнюю версию](https://github.com/starkovsavva/after/releases/latest)**
· Apple Silicon · macOS 15+ · RU / EN

**Встреча → конспект → источник.**
Запишите разговор или импортируйте аудио. After подготовит транскрипт и конспект:
решения, задачи и важные детали со ссылками на исходные реплики.
Название встречи и текст можно исправить после обработки.

<a href="docs/screenshots/summary.png"><img src="docs/screenshots/summary.png" width="900" alt="Конспект встречи с решениями, задачами и переходами к исходным репликам"></a>

**Заметки, которые легко найти.**
Записывайте свои мысли, сохраняйте важное из встреч, добавляйте вложения.
Поиск и совместные фильтры по происхождению, типу и теме помогают сузить список.
Происхождение — «Создано мной» или «Создано ИИ»; импорт входит в «Создано мной».
Условия можно убрать по одному; выбранные фильтры сохраняются.

<a href="docs/screenshots/notes.png"><img src="docs/screenshots/notes.png" width="900" alt="Библиотека заметок: поиск, фильтры и редактор"></a>

**База знаний с контекстом.**
Собирайте встречи и заметки по темам и в подборки, связывайте материалы вручную.
Откройте найденную заметку или встречу, чтобы проверить подробности в источнике.

<a href="docs/screenshots/knowledge.png"><img src="docs/screenshots/knowledge.png" width="900" alt="База знаний: темы, подборки и связанные материалы"></a>

**Задача → разрешённый снимок → результат агента.**
Выберите заметки из базы знаний, проверьте снимок и подтвердите доступ.
Агент читает эту копию; отчёт, ссылки на источники и артефакты появляются
в истории задачи. Изменения оригиналов не меняют снимок; доступ можно отозвать.

<a href="docs/screenshots/task-history.png"><img src="docs/screenshots/task-history.png" width="900" alt="История задачи: отчёт агента, источники и артефакты"></a>

**Карточки для повторения.**
Сохраняйте полезные фразы из встреч, редактируйте перевод и контекст.
Выберите колоду или отфильтруйте библиотеку и переходите к повторению по интервалам.

<a href="docs/screenshots/cards-library.png"><img src="docs/screenshots/cards-library.png" width="900" alt="Библиотека карточек с колодами, поиском и фильтрами перед повторением"></a>

На снимках — вымышленные материалы. Нажмите на изображение, чтобы открыть целиком.

## Установка

1. Скачайте **.pkg** по ссылке выше и запустите установщик.
2. Выберите модели и нужные возможности: [первый запуск и подключения](docs/setup.md).
3. Следующие обновления доступны в **Настройки → Обновления**.

Сборка без нотариализации Apple. Если macOS блокирует запуск, используйте
[штатное разрешение запуска](https://support.apple.com/102445).

Записи и библиотека хранятся на Mac. Можно выбрать локальные модели или облако;
при работе с облаком аудио или текст отправляются выбранному провайдеру.
API оплачивается отдельно; подключение ChatGPT использует лимиты подписки.

Ключи и сессии хранятся в Связке ключей macOS.
