# После

Приложение для Mac, чтобы не переслушивать встречи в поисках решений, задач и важных деталей.
Сохраняйте запись, работайте с конспектом и запоминайте полезные фразы.

**[Скачать для Mac](https://github.com/starkovsavva/posle/releases)** · Apple Silicon · macOS 15+

![Конспект встречи с решениями, задачами и ссылками на реплики](docs/screenshots/summary.png)

## Возможности

- **Встречи.** Запись звука или экрана, транскрипция на русском и английском, разделение собеседников и правка реплик.
- **Конспекты.** Решения, сроки и детали со ссылками на запись. События Google и Яндекса доступны через календарь macOS.
- **Задачи.** Список и доска, заметки и папки к задаче, история с результатами. Голосовые поручения и полный цикл работы агента через MCP.
- **Помощник.** Вопросы по встречам, заметкам, задачам, карточкам и подключённому календарю. Ответы со ссылками на источники.
- **Заметки.** Форматирование, чеклисты, папки и вложения. Общий поиск по библиотеке и голосовые поручения для заметок, задач и карточек.
- **Карточки.** Повторение с интервалами, примеры употребления, редактирование, импорт и экспорт.

Распознавание и конспекты работают с локальными моделями или через облако.
Для конспектов можно подключить [подписку ChatGPT](docs/chatgpt.md).

## Установка

1. Скачайте **Posle-Mac-AppleSilicon.pkg** из [Releases](https://github.com/starkovsavva/posle/releases).
2. Запустите установщик. Он обновит `/Applications/После.app` с сохранением библиотеки.
3. Выберите модели в настройках: [первый запуск и подключения](docs/setup.md).

Следующие версии можно устанавливать из приложения: **Настройки → Обновления**.

Сборка без нотариализации Apple. Если macOS блокирует запуск, воспользуйтесь
[штатным разрешением запуска](https://support.apple.com/102445).

Записи и библиотека хранятся на Mac. При выборе облака аудио или текст отправляются
выбранному провайдеру. API оплачивается отдельно; ChatGPT использует лимиты подписки.
Ключи и сессии хранятся в Связке ключей macOS.
