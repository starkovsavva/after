# После

Личное приложение для Mac: записать встречу, получить транскрипцию с собеседниками,
сохранить решения и детали, выучить полезные фразы и понятия.

**Требования:** Mac с Apple Silicon, macOS 15 или новее. Конфигурация Air M5 / 16 ГБ
подходит; модели распознавания, голосов и конспекта запускаются последовательно.

## Первый запуск

1. Распакуйте `dist/Posle-Mac-AppleSilicon.zip` и переместите `После.app` в «Программы».
2. Откройте приложение → **Настройки → Установить модели**. Приложение само загрузит
   изолированный Python, FFmpeg, Parakeet и модели разделения голосов. Homebrew не нужен.
3. Для полностью локального конспекта нажмите **Подготовить локальный ИИ**. Скачаются
   Ollama и выбранная Qwen3.5. По умолчанию — **9B Q4** для качества (скачивание 6,6 ГБ);
   быстрый режим — **4B Q4** (3,3 ГБ). На установку с одной моделью предусмотрите около
   15 ГБ свободного места; обе модели потребуют больше места. Размер скачивания не равен
   расходу оперативной памяти. Продолжительность первой настройки зависит от интернета. После неё можно работать офлайн.
4. Или выберите **Облако**, введите собственный API-ключ OpenAI и сохраните в Связку
   ключей macOS. По умолчанию используется `gpt-4.1-mini`; модель можно изменить.
   Подписка ChatGPT не оплачивает API-запросы.

Сборка подписана локальной ad-hoc подписью, без нотариализации Apple. При переносе на
другой Mac macOS может попросить разрешить её запуск через системные настройки
конфиденциальности. Это личная версия 0.2, не публикация в App Store.

Если после скачивания macOS блокирует запуск, сначала попробуйте открыть приложение,
затем перейдите в **Системные настройки → Конфиденциальность и безопасность → Безопасность**
и нажмите **Всё равно открыть** для «После», если эта кнопка появилась. Подтвердите запуск
в системном диалоге. Это разрешение относится к конкретному приложению.
[Инструкция Apple по первому запуску](https://support.apple.com/102445).

## Обычная встреча

- Нажмите **Записать встречу**. Для звонка выберите микрофон и звук Mac; для офлайн-встречи
  — только микрофон. Разрешения macOS запрашиваются при первом включении записи.
  Используйте наушники для звонков, чтобы микрофон не записывал звук динамиков повторно.
- По желанию включите **Также сохранить видео экрана**. Основной экран сохраняется
  в **MP4 / H.264, до 720p, 30 fps, 1 Мбит/с** — примерно 0,5 ГБ в час вместе со звуком.
  Без этого переключателя видеокадры не записываются.
- Нажмите **Остановить и сохранить**. Аудиозапись — **MP3**, в том числе при включённом видео.
  Для звонка дополнительные отдельные аудиодорожки сохраняются для точного разделения
  своего микрофона и остальных голосов. Временный аудиоконтейнер удаляется после успешного
  преобразования в MP3.
- Можно просто перетащить MP3, M4A, WAV, MP4, MOV, FLAC или WebM. У импортированного видео
  извлекается звук; исходник сохраняется как резервная копия.
- Речь распознаётся на исходном языке: русский, английский, переключения между ними.
  Качество смешанной речи и терминов нужно проверять на ваших записях.
- Нажмите имя участника в транскрипте, чтобы переименовать его. При пересечении голосов
  приложение показывает неопределённость. Если известное число участников помогает,
  укажите его в настройках и выберите «Распознать заново» в меню встречи.
- На вкладке **Конспект** уточните, что важно: сроки, деньги, требования, технические детали,
  английские выражения. Верхний итог ограничен 2–3 предложениями, до 600 символов;
  решения, задачи и точные детали сохраняются отдельно. Кнопка «Исправить» позволяет
  сохранить свою редакцию краткого итога. Можно отмечать выполненные задачи. Таймкод открывает исходную
  реплику и запускает аудио с этого места.

В локальном режиме конспект может создаваться автоматически. В облачном — только
кнопкой **Конспект в облаке**: отправляется текст, аудио остаётся на Mac. Приложение
просит API не сохранять response (`store: false`); условия обработки провайдера
всё равно применяются. Автоматического перехода с локального режима в облако нет.

## Карточки

Карточка содержит один вопрос или английскую фразу, короткий ответ и исходную цитату.
Нажмите **Показать ответ**, затем оцените: **Снова / Трудно / Хорошо / Легко**.
FSRS рассчитывает следующий показ с целевым удержанием 90%; история хранится между запусками.
Пробел раскрывает ответ, клавиши 1–4 выбирают оценку. ⌘1 / ⌘2 / ⌘3 переключают
конспект, транскрипт и карточки. Интерфейс поддерживает светлую и тёмную темы macOS.

**Придумать пример** создаёт новое английское предложение, перевод и пояснение.
Пример явно отделён от настоящей цитаты и не меняет историю повторения. Кнопка
**Придумать другой пример** обновляет его. В облачном режиме отправляется только
карточка, её контекст и предыдущий пример, а не вся встреча.

**Экспорт в Anki** сохраняет TSV. В Anki выберите «Импортировать файл» и тип заметки Basic:
поля Front → лицевая сторона, Back → ответ, Tags → теги. Экспорт переносит содержание
карточек; историю FSRS этого приложения он не переносит.

## Данные и надёжность

Данные: `~/Library/Application Support/Posle`. В настройках есть кнопка открытия папки.
Каждая встреча лежит в отдельной папке: исходник, MP3, `meta.json`, `transcript.json`,
`summary.json`, `examples.json`, `review-state.json`, `review-log.jsonl` и необязательное `video.mp4`.
Сделайте резервную копию этой папки, если записи важны.

JSON сохраняется атомарно. Прерванные задачи остаются доступными для повторного запуска;
исходная запись не удаляется. При ошибке конспекта транскрипция остаётся сохранённой.
Длинные встречи обрабатываются целиком по частям, включая конец записи. Готовые части
прерванного конспекта используются повторно только при совпадении исходного текста,
модели и настроек; повреждённый кеш игнорируется. Ссылки на
несуществующие реплики и карточки с выдуманными цитатами отбрасываются. Ссылки проверяют
место в записи, но не гарантируют правильность вывода ИИ: важные обязательства и цифры
стоит сверять с аудио.

Приложение не поднимает HTTP-сервер для своей библиотеки. Локальная Ollama слушает только
`127.0.0.1` (порт из диапазона 11436–11456), облачные функции Ollama отключены.
Удалённые модели в локальном режиме отвергаются; системный HTTP-прокси для локальных
запросов не используется. API-ключ не пишется в настройки,
логи или аргументы команд. Основное приложение не использует телеметрию. Загрузки моделей
при первичной настройке требуют обращения к GitHub, Hugging Face, PyPI и реестру Ollama.

Ограничения 0.2: нет потокового текста во время записи, синхронизации между Mac,
автоматического определения имён, редактирования границ реплик и импорта истории Anki.
Диаризация и ИИ могут ошибаться при шуме и одновременной речи. Проверка реальных
разрешений записи и полного звонка на вашем личном Air остаётся частью первого запуска.

## Сборка из исходников

Понадобятся Command Line Tools for Xcode (Swift 5.10+ с SDK macOS 15+) и Rust 1.89+.
`scripts/setup-rust.sh` устанавливает изолированный Rust в `.toolchain/`, не меняя профиль
оболочки. Пользователю готового приложения Rust, Python и Homebrew устанавливать вручную не нужно.

```bash
cd /путь/к/posle
bash scripts/setup-rust.sh
bash scripts/build.sh
open dist/После.app
```

```bash
POSLE_PYTHON="/путь/к/runtime/venv/bin/python" bash scripts/check.sh
```

Для тестов, не затрагивающих личную библиотеку, задайте `POSLE_DATA_DIR` с отдельной папкой.
`--preview --snapshot /absolute/path.png` сохраняет изображение собственного окна приложения,
не снимок экрана пользователя. Для визуальной проверки доступны `--appearance dark`,
`--width 1040 --height 700`, `--preview-tab cards --preview-answer` и
`--preview-screen settings|record|recording|saving|welcome|processing|empty-search|cards-empty|error`.
Предпросмотр использует отдельные демонстрационные данные и не читает API-ключ.

Архитектура: нативный SwiftUI/AppKit и ScreenCaptureKit/AVFoundation для интерфейса
и захвата; Rust-библиотека через стабильный JSON C ABI для импорта и атомарного хранения;
Rust-worker для конспектов, примеров, FSRS и управления процессами. Короткоживущий
Python-worker нужен только для Parakeet MLX, Sherpa ONNX и FFmpeg. Отдельная Ollama
выполняет локальные LLM-запросы; облачный режим использует OpenAI Responses API.
Структура ответа, цитаты и идентификаторы исходных реплик проверяются в Rust.
Сервер и внешняя база для личной библиотеки не нужны.

На Air 16 ГБ локальный контекст ограничен 16k, длинные встречи делятся на части.
Рекомендуемые модели: `qwen3.5:9b-q4_K_M` и `qwen3.5:4b-q4_K_M`. Это выбор по
официальным характеристикам, а не измерение скорости на Air: реальная скорость зависит
от длины встречи, других приложений и нагрева. Варианты доступны в настройках.

При изучении [Meetily](https://github.com/Zackriya-Solutions/meetily) использованы идеи
явного редактирования конспекта и управления обработкой. Исходный код Meetily в приложение
не переносился; интерфейс После написан отдельно на SwiftUI.

Источники: [Parakeet MLX](https://github.com/senstella/parakeet-mlx),
[Sherpa ONNX](https://github.com/k2-fsa/sherpa-onnx),
[FSRS Rust](https://github.com/open-spaced-repetition/fsrs-rs),
[Ollama API](https://docs.ollama.com/api/chat),
[Qwen3.5](https://huggingface.co/Qwen/Qwen3.5-9B),
[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
Сторонние компоненты и лицензии перечислены в `THIRD_PARTY.md`.
