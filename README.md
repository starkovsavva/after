# После

Личное приложение для Mac: записать встречу, получить транскрипцию с собеседниками,
сохранить решения и детали, выучить полезные фразы и понятия.

**[Скачать готовое приложение для Mac](https://github.com/starkovsavva/posle/releases)**

В последнем релизе откройте **Assets → Posle-Mac-AppleSilicon.pkg** — установщик приложения.
Также доступен ZIP с готовым `После.app`; архивы `Source code` содержат исходники. Репозиторий приватный: войдите
в GitHub под аккаунтом с доступом. Готовые сборки публикуются в Releases при каждом
выпуске версии.

**Требования:** Mac с Apple Silicon, macOS 15 или новее. Конфигурация Air M5 / 16 ГБ
подходит. В управляемом режиме «После» распознавание, разделение голосов и конспект
запускаются последовательно; память внешних Ollama и LM Studio настраивается в этих приложениях.

## Первый запуск

1. Откройте `Posle-Mac-AppleSilicon.pkg`: установщик поместит `После.app` в «Программы».
   Или распакуйте ZIP и перенесите приложение туда вручную.
2. Откройте приложение → **Настройки → Установить модели**. Приложение само загрузит
   изолированный Python, FFmpeg, Parakeet и модели разделения голосов. Homebrew не нужен.
3. Для полностью локального конспекта нажмите **Подготовить локальный ИИ**. Скачаются
   Ollama и выбранная Qwen3.5. По умолчанию — **9B Q4** для качества (скачивание 6,6 ГБ);
   быстрый режим — **4B Q4** (3,3 ГБ). На установку с одной моделью предусмотрите около
   15 ГБ свободного места; обе модели потребуют больше места. Размер скачивания не равен
   расходу оперативной памяти. Продолжительность первой настройки зависит от интернета. После неё можно работать офлайн.
4. Или выберите **Облако**, введите собственный API-ключ OpenAI и сохраните в Связку
   ключей macOS. По умолчанию используется `gpt-4.1-mini`; модель можно изменить.
   Подписка ChatGPT не оплачивает API-запросы.

Сборка подписана локальной ad-hoc подписью, без нотариализации Apple. При переносе на
другой Mac macOS может попросить разрешить её запуск через системные настройки
конфиденциальности. Это личная версия 0.5, не публикация в App Store.

Если после скачивания macOS блокирует запуск, сначала попробуйте открыть приложение,
затем перейдите в **Системные настройки → Конфиденциальность и безопасность → Безопасность**
и нажмите **Всё равно открыть** для «После», если эта кнопка появилась. Подтвердите запуск
в системном диалоге. Это разрешение относится к конкретному приложению.
[Инструкция Apple по первому запуску](https://support.apple.com/102445).

Если кнопки нет и появляется только «Не удаётся открыть программу», для этой личной
сборки можно проверить подпись и снять метку скачивания с её папки. Пример для
приложения, распакованного в «Загрузки»:

```bash
posle_app="$HOME/Downloads/После.app"
codesign --verify --deep --strict --verbose=2 "$posle_app" &&
xattr -dr com.apple.quarantine "$posle_app" &&
open "$posle_app"
```

## Если модели уже скачаны

В **Настройках → Распознавание речи** нажмите **Найти на Mac** или выберите папку
Parakeet вручную. Поиск работает до установки среды и проверяет стандартные папки
Hugging Face и стандартные каталоги локальных моделей. Поддерживаются готовый `model.safetensors` Parakeet MLX,
NeMo ONNX (`encoder-model`, `decoder_joint-model`, `nemo128.onnx`, `vocab.txt`)
и Sherpa ONNX (`encoder`, `decoder`, `joiner`, `tokens.txt`). Все части должны быть скачаны.
Форматы GGUF и `.nemo` не подключаются как Parakeet MLX/ONNX. Parakeet v2 рассчитан
на английский; для русского и английского выбирайте v3.

Веса используются по существующему пути, без копирования и повторного скачивания.
Не удаляйте эту папку, пока модель используется в После. При ошибке явно выбранной
папки приложение остановится и покажет причину. При автоматическом выборе подготовка
сначала ищет совместимую модель и скачивает стандартную MLX только если подходящей нет.
Отдельные среда Python, FFmpeg и модели собеседников всё равно нужны. После обновления
с 0.2 нажмите **Подготовить распознавание**, чтобы установить новый ONNX-адаптер;
уже имеющиеся совместимые веса сохраняются. ONNX работает на CPU, его скорость может
отличаться от MLX на Apple Silicon.

Для уже скачанной Qwen или другой текстовой модели выберите **Конспект и примеры →
На Mac → Ollama / LM Studio**, нажмите **Найти установленные модели** и выберите нужную.
Ollama должна быть запущена. В LM Studio включите локальный сервер в разделе Developer;
он должен видеть скачанную модель (при выключенном JIT загрузите её вручную).
После не скачивает и не выгружает модели внешнего сервера и не останавливает его.
Обычные адреса — `http://127.0.0.1:11434` и `http://127.0.0.1:1234`.
Только HTTP loopback; удалённые адреса и облачные модели Ollama не допускаются.
Чтобы текст оставался на этом Mac, отключите **LM Link** в LM Studio. Настройки
контекста и потребления памяти внешнего сервера остаются под управлением этого приложения.

Уже скачанная Qwen или другая модель может лежать отдельным GGUF-файлом.
В источнике **После** откройте **Подключить модель из файла → Найти модели на Mac**,
затем **Подключить**. Можно выбрать файл вручную. Сначала должна быть
подготовлена среда распознавания. Приложение устанавливает только локальный движок
и регистрирует уже имеющийся GGUF; скачивание Qwen из реестра не запускается.
Совместимость конкретной архитектуры окончательно проверяет Ollama при подключении.
Исходный файл остаётся неизменным. На APFS используется независимый клон с общими блоками данных;
на другом файловом томе может понадобиться место для локальной копии. Клон имеет
собственные атрибуты: действия движка не меняют исходный файл модели.

Вариант **После** по-прежнему устанавливает собственный изолированный движок и Qwen.
Списки установленных моделей обновляются без скачивания. Для конспекта важна поддержка
структурированного JSON выбранной текстовой моделью; не каждая старая Qwen даёт
одинаковое качество заметок.

## Обычная встреча

- Нажмите **Записать встречу**. Для звонка выберите микрофон и звук Mac; для офлайн-встречи
  — только микрофон. Разрешения macOS запрашиваются при первом включении записи.
  Используйте наушники для звонков, чтобы микрофон не записывал звук динамиков повторно.
- По желанию включите **Также сохранить видео экрана**. Основной экран сохраняется
  в **MP4 / H.264, до 720p, 30 fps, 1 Мбит/с** — примерно 0,5 ГБ в час вместе со звуком.
  Без этого переключателя видеокадры не записываются.
- Нажмите **Остановить и сохранить**. Аудиозапись — **MP3**, в том числе при включённом видео.
  Для звонка дополнительные отдельные аудиодорожки сохраняются для точного разделения
  своего микрофона и остальных голосов. Временный аудиоконтейнер удаляется после успешного
  преобразования в MP3.
- Можно просто перетащить MP3, M4A, WAV, MP4, MOV, FLAC или WebM. У импортированного видео
  извлекается звук; исходник сохраняется как резервная копия.
- Речь распознаётся на исходном языке: русский, английский, переключения между ними.
  Качество смешанной речи и терминов нужно проверять на ваших записях.
- Нажмите имя участника в транскрипте, чтобы переименовать его. При пересечении голосов
  приложение показывает неопределённость. Если известное число участников помогает,
  укажите его в настройках и выберите «Распознать заново» в меню встречи.
- На вкладке **Конспект** уточните, что важно: сроки, деньги, требования, технические детали,
  английские выражения. Верхний итог ограничен 1–3 предложениями, до 600 символов;
  решения, задачи и точные детали сохраняются отдельно. Кнопка «Исправить» позволяет
  сохранить свою редакцию краткого итога. Можно отмечать выполненные задачи. Таймкод открывает исходную
  реплику и запускает аудио с этого места.

В локальном режиме конспект может создаваться автоматически. В облачном — только
кнопкой **Конспект в облаке**: отправляется текст, аудио остаётся на Mac. Приложение
просит API не сохранять response (`store: false`); условия обработки провайдера
всё равно применяются. Автоматического перехода с локального режима в облако нет.

## Общий поиск и ссылки на факты

Нажмите **⌘K** или **Поиск по всей библиотеке** в боковой панели. Поиск работает по
названиям, кратким конспектам, решениям, задачам, важным деталям, репликам и карточкам.
Фильтры ограничивают результаты конспектами, транскриптом, карточками или названиями.
Сохраняется и отдельный фильтр названий встреч в боковой панели.

Поддерживаются русские и английские словоформы, неполное начало слова и одинаковый
поиск с «е»/«ё». Несколько слов уточняют запрос: они должны встретиться в одном
фрагменте. Это поиск по тексту, а не генерация ответов или поиск семантических синонимов.
Например, запрос «бюджет» найдёт «бюджета», но не обязан находить любую фразу о деньгах.
Поиск полностью локальный, без моделей, API-ключей и отправки заметок на сервер.

В результатах видны встреча, дата, тип фрагмента, отрывок и таймкод, если он есть.
↑/↓ выбирают результат, Return открывает его, Esc закрывает поиск. Приложение переходит
к нужной встрече и выделяет фрагмент; звук сам не включается. Таймкод в исходной
реплике позволяет отдельно начать воспроизведение.

Локальный индекс находится в `cache/search/index.sqlite` внутри папки данных. Он
создаётся из JSON и обновляет изменённые встречи при следующем поиске; удалённые и
устаревшие совпадения исключаются. Индекс можно пересоздать, источником истины остаются
файлы встреч. Перед переходом проверяется, что найденная версия фрагмента ещё актуальна.
Старые конспекты индексируются без повторного обращения к ИИ.

Новые краткие конспекты содержат ссылки **[1]**, **[2]** рядом с утверждениями.
Нажмите ссылку: откроются факты, на которых построено утверждение, и исходные реплики
с именами участников и таймкодами. **Открыть в транскрипте** переносит к точной реплике;
кнопка воспроизведения включает запись с этого места. У каждого отдельного факта
также доступны все его исходные реплики, а не только первый таймкод.

Для старого конспекта доступны его факты и их источники; чтобы получить ссылки из
самого краткого итога, обновите конспект. После ручного редактирования краткого итога
старые ссылки с него снимаются: они не выдаются за подтверждение нового текста.
Сами факты, карточки и история повторений сохраняются. Ссылки показывают происхождение
информации и не гарантируют, что ИИ правильно понял исходный разговор.

## Обновление поверх старой версии

Закройте После и откройте новый `Posle-Mac-AppleSilicon.pkg`. Он заменит приложение
в `/Applications/После.app`; вручную удалять прежнюю версию не нужно. Идентификатор
приложения постоянный, установщик не содержит скриптов и не трогает папку данных,
модели или Связку ключей. Не перемещайте данные в Корзину при обновлении.

Если раньше запускали копию из «Загрузок», после первой установки пакетом откройте
После из «Программ» и закрепите эту копию в Dock. Последующие пакеты обновляют её
по тому же пути. Другая копия из «Загрузок» автоматически не удаляется.
В **Настройках → Данные и экспорт** есть ссылка на страницу обновлений.
Это ручная установка скачанного пакета; фонового автообновления пока нет.

Пакет пока без Developer ID подписи и нотариализации. Если macOS блокирует установщик,
можно использовать ZIP и заменить приложение в «Программах» с подтверждением Finder;
инструкция разрешения запуска личной сборки приведена выше.

## Быстрые заметки, шаблоны и контекст

- **⌃⌥N** открывает маленькое окно из любого приложения. Напишите мысль и нажмите
  **⌘Return**. Во время записи она попадёт в текущую встречу, иначе — во **Входящие**.
  Текст сохраняется кнопкой; черновик открытого окна сохраняется в памяти до закрытия приложения.
- **⌃⌥B** или кнопка **Важно** во время записи ставит пометку с таймкодом. Можно также
  отмечать место при прослушивании. Нажатие на таймкод открывает реплику без включения звука.
- В каждой встрече есть **Мои заметки**. Тип пометки: заметка, важно, вопрос или задача.
  Собственный текст редактируется независимо от транскрипта и конспекта.
- В редакторе заметки доступны **Добавить файл**, вставка из буфера и перетаскивание.
  Изображения, PDF и текстовые вложения копируются в приватную папку приложения;
  исходные файлы не меняются. **Распознать текст** использует Apple Vision на Mac
  для русского и английского; результат ищется через ⌘K. Файлы не отправляются в ИИ.
- **Развернуть** подбирает к пометке дословные цитаты из транскрипта и предлагает вопросы
  для уточнения. Исходная пометка остаётся отдельно. Кнопки источников ведут к точным
  репликам. После изменения транскрипта ссылки требуют обновления дополнения.
  На длинных встречах используется ограниченный контекст с предупреждением; отсутствие
  ответа в выбранных фрагментах не доказывает его отсутствие во всей встрече.
- **Контекст и шаблон** связывает встречу с проектом и человеком и позволяет выбрать
  готовый или свой шаблон. Встроены закупки, собеседование, 1:1 и английский.
  Структуру можно добавить отдельной заметкой, фокус шаблона — применить к конспекту.
- В **Проекты и люди** видны связанные разговоры, решения, открытые вопросы и незавершённые
  задачи. Это сводка сохранённых источников, без дополнительной генерации ИИ.
- **Мои задачи** собирают собственные задачи и поручения из конспектов всех встреч.
  Своей задаче можно указать ответственного и срок; выполнение синхронизируется с встречей.

Входящие подходят и для повестки до звонка: потом привяжите заметку к созданной встрече.
Ручные заметки из удалённой встречи остаются во Входящих с указанием недоступной записи.
Они не удаляются вместе с аудио и могут быть привязаны заново.

Настройки разделены на **Общие**, **Запись**, **Распознавание речи**, **Конспект и модели**,
**Заметки и шаблоны**, **Горячие клавиши**, **Данные и экспорт**. Можно выбрать стартовый
экран, шаблон новых встреч и сочетание быстрой заметки ⌃⌥N или ⌃⇧Пробел, отключить
глобальные сочетания. При конфликте сочетания остаётся кнопка в строке меню.
Сначала сохраните настройки, чтобы новые сочетания вступили в силу.

## Карточки

Раздел **Карточки** в боковой панели — общая колода из всех встреч и импортов.
Есть фильтр колоды, поиск и режим всех карточек; повторение работает прямо в После.
Карточки также доступны на вкладке каждой встречи.

Карточка содержит один вопрос или английскую фразу, короткий ответ и исходную цитату.
Нажмите **Показать ответ**, затем оцените: **Снова / Трудно / Хорошо / Легко**.
FSRS рассчитывает следующий показ с целевым удержанием 90%; история хранится между запусками.
Пробел раскрывает ответ, клавиши 1–4 выбирают оценку. ⌘1 / ⌘2 / ⌘3 переключают
конспект, транскрипт и карточки. Интерфейс поддерживает светлую и тёмную темы macOS.

**Придумать пример** создаёт новое английское предложение, перевод и пояснение.
Пример явно отделён от настоящей цитаты и не меняет историю повторения. Кнопка
**Придумать другой пример** обновляет его. В облачном режиме отправляется только
карточка, её контекст и предыдущий пример, а не вся встреча.

**Экспорт в Anki** сохраняет TSV. В Anki выберите «Импортировать файл» и тип заметки Basic:
поля Front → лицевая сторона, Back → ответ, Tags → теги. Экспорт переносит содержание
карточек; историю FSRS этого приложения он не переносит.

**Импорт** принимает UTF-8 TSV/CSV и текстовый экспорт Anki. Сначала показывается
предпросмотр с выбором разделителя; первые два столбца — вопрос и ответ, именованный
Context/Контекст — дополнительный контекст. Теги Anki не считаются контекстом.
Поддерживаются кавычки, многострочные поля и стандартные текстовые заголовки Anki;
HTML превращается в обычный текст. Дубликаты и неполные строки пропускаются с отчётом.
При изменении файла после предпросмотра импорт останавливается до обновления просмотра.

Импортированные карточки образуют отдельную колоду и начинают повторяться как новые.
Медиа, cloze-шаблоны, файлы `.apkg` и история повторений Anki не переносятся;
для них нужен обычный текстовый экспорт с вопросами и ответами.

## Данные и надёжность

Данные: `~/Library/Application Support/Posle`. В настройках есть кнопка открытия папки.
Каждая встреча лежит в отдельной папке: исходник, MP3, `meta.json`, `transcript.json`,
`summary.json`, `examples.json`, `review-state.json`, `review-log.jsonl` и необязательное `video.mp4`.
Ручные заметки, шаблоны и связи хранятся в `notes/workspace.json`, вложения — в
`notes/attachments/`. У каждой правки есть ревизия: устаревшее окно не может молча
перезаписать новый текст. В настройках доступен Markdown-экспорт ручных заметок.
Сделайте резервную копию всей папки, если записи важны.

JSON сохраняется атомарно. Прерванные задачи остаются доступными для повторного запуска;
исходная запись не удаляется. При ошибке конспекта транскрипция остаётся сохранённой.
Длинные встречи обрабатываются целиком по частям, включая конец записи. Готовые части
прерванного конспекта используются повторно только при совпадении исходного текста,
модели и настроек; повреждённый кеш игнорируется. Ссылки на
несуществующие реплики и карточки с выдуманными цитатами отбрасываются. Ссылки проверяют
место в записи, но не гарантируют правильность вывода ИИ: важные обязательства и цифры
стоит сверять с аудио.

Приложение не поднимает HTTP-сервер для своей библиотеки. Локальная Ollama слушает только
`127.0.0.1` (порт из диапазона 11436–11456), облачные функции Ollama отключены.
У внешних Ollama / LM Studio выбранный пользовательский сервер управляет своей моделью;
для LM Studio нужно отключить LM Link, чтобы текст оставался на этом Mac.
Удалённые адреса и известные облачные модели в локальном режиме отвергаются; системный HTTP-прокси для локальных
запросов не используется. API-ключ не пишется в настройки,
логи или аргументы команд. Основное приложение не использует телеметрию. Загрузки моделей
при первичной настройке требуют обращения к GitHub, Hugging Face, PyPI и реестру Ollama.

Ограничения 0.5: нет потокового текста во время записи, синхронизации между Mac,
автоматического определения имён, редактирования границ реплик и импорта истории Anki.
Диаризация и ИИ могут ошибаться при шуме и одновременной речи. Проверка реальных
разрешений записи и полного звонка на вашем личном Air остаётся частью первого запуска.

## Сборка из исходников

Понадобятся Command Line Tools for Xcode (Swift 5.10+ с SDK macOS 15+) и Rust 1.89+.
`scripts/setup-rust.sh` устанавливает изолированный Rust в `.toolchain/`, не меняя профиль
оболочки. Пользователю готового приложения Rust, Python и Homebrew устанавливать вручную не нужно.

```bash
cd /путь/к/posle
bash scripts/setup-rust.sh
bash scripts/build.sh
open dist/После.app
```

```bash
POSLE_PYTHON="/путь/к/runtime/venv/bin/python" bash scripts/check.sh
```

Для тестов, не затрагивающих личную библиотеку, задайте `POSLE_DATA_DIR` с отдельной папкой.
`--preview --snapshot /absolute/path.png` сохраняет изображение собственного окна приложения,
не снимок экрана пользователя. Для визуальной проверки доступны `--appearance dark`,
`--width 1040 --height 700`, `--preview-tab cards --preview-answer` и
`--preview-screen settings|record|recording|saving|welcome|processing|empty-search|cards-empty|error|notes|inbox|tasks|contexts|cards-library|quick-note|note-editor`.
Для настроек можно задать `--settings-section general|record|speech|ai|notes|keys|data`.
Предпросмотр использует отдельные демонстрационные данные и не читает API-ключ.

Архитектура: нативный SwiftUI/AppKit и ScreenCaptureKit/AVFoundation для интерфейса
и захвата; Rust-библиотека через стабильный JSON C ABI для импорта и атомарного хранения;
Rust-worker для конспектов, примеров, FSRS и управления процессами. Короткоживущий
Python-worker нужен только для Parakeet MLX/ONNX, Sherpa ONNX и FFmpeg. Отдельная Ollama
выполняет локальные LLM-запросы; облачный режим использует OpenAI Responses API.
Структура ответа, цитаты и идентификаторы исходных реплик проверяются в Rust.
Сервер и внешняя база для личной библиотеки не нужны.

На Air 16 ГБ локальный контекст ограничен 16k, длинные встречи делятся на части.
Рекомендуемые модели: `qwen3.5:9b-q4_K_M` и `qwen3.5:4b-q4_K_M`. Это выбор по
официальным характеристикам, а не измерение скорости на Air: реальная скорость зависит
от длины встречи, других приложений и нагрева. Варианты доступны в настройках.

Проверка полнотекстового поиска через настоящий C ABI без моделей и личных данных:

```bash
python3 scripts/check_search.py --library dist/После.app/Contents/Frameworks/libposle_core.dylib
```

Публикация версии после коммита, push и обновления номера в `packaging/Info.plist`:

```bash
python3 scripts/publish_release.py --notes-file /путь/к/описанию-релиза.md
```

Скрипт собирает приложение и обязательно прикладывает установщик
`Posle-Mac-AppleSilicon.pkg`, архив `Posle-Mac-AppleSilicon.zip`, исходники и `SHA256SUMS` в GitHub Releases. Сначала создаётся черновик; он
публикуется только после проверки размеров и SHA-256 загруженных файлов. `--check-only`
проверяет локальные архивы без обращения к GitHub, `--skip-build` использует уже
проверенную сборку. Публичные репозитории этим личным helper не обслуживаются.
