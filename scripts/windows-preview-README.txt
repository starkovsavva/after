After Preview 0.1.1 — Windows x64 (Intel/AMD)

Тестовый установщик для Windows 10/11. Это не публичный релиз и не полная
замена версии для Mac. Приложение и движок собраны вместе; отдельно переносить
после установки After.exe или engine/ не нужно.

Запустите After-Preview-0.1.1-Windows-x64-setup.exe. Установка выполняется
для текущего пользователя. При необходимости установщик скачает Microsoft
WebView2 — для этого понадобится интернет. Подписи издателя пока нет.
SHA-256 установщика указан в SHA256SUMS.txt.

Что можно проверить:
- Создать папку и заметку, написать русский и английский текст.
- Сохранить Ctrl+S, закрыть приложение и проверить сохранённый текст после запуска.
- Переименовать папку, убедиться, что заметки остались в ней.
- Открыть поиск Ctrl+K, искать заметки в папке и во всей библиотеке.
- Переключить русский/английский интерфейс, светлую/тёмную тему.
- Начать несохранённую заметку и попробовать перейти в другой раздел/закрыть окно.

Запись, импорт встреч, распознавание, генерация конспектов, ИИ-помощник,
календарь, задачи и карточки ещё не подключены. Подписка ChatGPT/API не нужна.
Это приложение создаёт отдельную локальную библиотеку app.posle.desktop;
к установленной версии для Mac и её данным не подключается.

При ошибке пришлите версию Windows, шаги, ожидаемый результат и скриншот.
Пароли, токены и личное содержимое библиотеки присылать не нужно.
