# Синтетический набор для смешанных тем

`mixed-holdout-v1.json` содержит пять искусственных пар заметок и встреч и используется только для воспроизводимого отчёта и регрессий. Он маленький и не представляет реальные библиотеки. Его данные и полученные результаты уже известны разработке: после любых изменений, учитывающих этот набор, он не является независимой финальной оценкой качества.

Не подбирать пороги по этому набору и не считать прохождение теста разрешением на включение функции. Для выбора порогов нужен отдельный калибровочный корпус; до решения о включении дополнительно нужен новый скрытый, заранее размеченный и не использованный при разработке проверочный набор, включающий разные языки, парафразы, похожие, но независимые проекты, а также оценки precision, recall и покрытия. Эти данные собираются отдельно с согласия владельцев. Смешанные темы остаются закрытыми до решения вопросов приватности, идентичности и проверки качества.

Запуск из корня репозитория: `cargo test --manifest-path rust-core/Cargo.toml synthetic_holdout_reports_quality_without_a_pass_threshold -- --nocapture`. В отчёте фиксируются ревизия исходников, хеш fixture и `Cargo.lock`, версии Rust и параметры алгоритма; количество правильных, ложных и пропущенных связей выводится тестом. Для сравнения изменений нужен один и тот же набор и неизменная разметка.
